# Verificación del flujo de pull requests

Para comprobar el acceso de un colaborador al repositorio:

1. Crear una rama con un cambio pequeño de documentación.
2. Subir la rama y abrir un pull request hacia `main`.
3. Revisar las aprobaciones y verificaciones que GitHub solicite.
4. Si aparece una vista previa de Vercel, comprobar su resultado.

La creación del pull request confirma el acceso para proponer cambios.
No confirma por sí sola permisos para integrar cambios ni desplegar a producción.
